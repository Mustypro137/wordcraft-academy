# PROJECT: WordCraft Academy — Private English & Communication Learning Platform

## 1. Your Role

Act as a senior full-stack developer, English-language learning specialist, educational product designer, UX/UI designer, and technical mentor.

Help me build a beautiful, modern, interactive and private English-learning platform.

I am a beginner developer. Teach me while we build this project.

Do not simply generate an entire application without explaining it. Work like a real development team: plan, discuss, implement, test, review and improve.

## 2. Main Project Goal

Build a personal educational website that helps learners:

- Learn everyday English vocabulary.
- Understand unfamiliar words.
- Build natural sentences without translating every word.
- Write like ordinary fluent English speakers.
- Communicate naturally in conversations and messages.
- Learn professional and technical vocabulary.
- Improve prompt-writing skills.
- Understand vocabulary used in web development, programming, UI/UX design, AI and Claude Code.
- Remember and confidently use new words.

The platform must support children, teenagers and adults.

It should work as a private, personal learning environment, not a public social network.

## 3. Learning Philosophy

The most important problem to solve:

A learner may want to write a sentence but cannot find the correct words. The learner should never be forced to memorize vocabulary before being allowed to write.

Build a system that teaches vocabulary through recognition, examples, sentence construction, practice and real-world usage.

Use these principles:

1. Understand before memorizing.
2. Recognize words before expecting independent usage.
3. Learn words inside real sentences.
4. Learn phrases and sentence patterns, not isolated words only.
5. Practice writing without copying examples.
6. Give hints before revealing complete answers.
7. Review unfamiliar words regularly.
8. Encourage independent sentence construction.

## 4. User Profiles and Learning Levels

Create three age-based learning experiences:

- Kids: simple explanations, familiar examples, colorful activities and fun challenges.
- Teenagers: school, hobbies, technology, friendships and everyday communication.
- Adults: everyday life, professional writing, business, programming and career communication.

Create four language difficulty levels:

- Beginner (A1–A2)
- Intermediate (B1–B2)
- Advanced (C1)
- Expert / Professional English

Use CEFR levels where appropriate.

Allow learners to change their learning level independently of their age group.

## 5. Main Features

### A. Vocabulary Explorer

Create organized vocabulary libraries.

Categories:

- Everyday English
- Common verbs
- Common nouns
- Adjectives
- Adverbs
- Natural conversation
- Communication
- Professional writing
- Business English
- Web development
- Programming
- UI/UX design
- AI and artificial intelligence
- Prompt engineering
- Claude Code
- Vibe coding
- Freelancing and client communication
- Technology

Every vocabulary entry should include:

- Word
- Simple definition
- Part of speech
- Difficulty level
- Pronunciation guide
- Example sentences
- Common phrases and collocations
- Synonyms where useful
- Opposite words where useful
- Common mistakes
- Real-life situation
- A short exercise

Do not create enormous meaningless word lists. Prioritize useful, frequently used vocabulary.

### B. Vocabulary Knowledge Cards

Every vocabulary word should have an interactive card.

Provide four actions:

1. I know this word.
2. I have seen this word.
3. I don't know this word.
4. I want to practice this word.

Organize vocabulary into four personal collections:

- Known Words
- Learning Words
- Unfamiliar Words
- Mastered Words

When a learner selects "I don't know this word", automatically save it to the Unfamiliar Words collection.

Allow learners to move words between collections.

Show word definitions and examples whenever needed.

Do not mark a word as mastered simply because the learner clicks a button. Use successful practice and recall exercises to measure mastery.

### C. Sentence Builder

Teach learners how to construct sentences naturally.

Include:

- Subject + verb + object.
- Everyday sentence patterns.
- Questions and answers.
- Positive and negative sentences.
- Connecting words.
- Describing people, places and situations.
- Giving opinions.
- Explaining problems.
- Asking for help.
- Giving instructions.
- Expressing feelings and preferences.

Teach common sentence starters:

- I think...
- I want to...
- I need to...
- I am trying to...
- Could you help me...
- The reason is...
- What I mean is...
- I would like to...

Allow learners to combine words into sentences through interactive word tiles.

Gradually remove hints as learners improve.

### D. Natural Writing Studio

Create a writing practice environment.

Writing situations:

- Everyday conversations.
- WhatsApp messages.
- Talking with friends and family.
- Asking questions.
- Explaining problems.
- Giving opinions.
- Writing emails.
- LinkedIn posts.
- Client communication.
- Project requirements.
- Website descriptions.
- Professional messages.

When the learner writes:

1. Identify unfamiliar or difficult vocabulary.
2. Suggest useful words and phrases.
3. Explain why a word fits the sentence.
4. Give a small hint first.
5. Let the learner try independently.
6. Correct grammar and unnatural expressions.
7. Provide a natural version.
8. Explain the improvements.
9. Save useful new vocabulary to personal collections.

Never replace the learner's writing immediately. Encourage independent thinking.

### E. Vocabulary While Writing

This is a particularly important feature.

Create an optional vocabulary assistant inside the writing editor.

Example:

Learner writes:
"I want to make my website more good."

The assistant helps:

- Better: improve.
- More natural: "I want to improve my website."
- Explanation: Improve means to make something better.

Allow the learner to save "improve" to their vocabulary collection.

Allow learners to continue writing even when they cannot find the right word.

Topics:

1. HTML and CSS.
2. JavaScript.
3. React and TypeScript.
4. Python.
5. Git and GitHub.
6. Frontend development.
7. Backend development.
8. APIs.
9. Databases.
10. UI/UX design.
11. Responsive design.
12. Web deployment.
13. AI engineering.
14. Prompt engineering.
15. Claude Code.
16. Vibe coding.

Teach the meaning of technical words and show how developers use them in actual conversations and project requirements.

Example:

"Implement a responsive navigation component."

Explain:
- Implement = build or add something.
- Responsive = adapts to different screen sizes.
- Navigation = the section that helps users move around a website.
- Component = a reusable part of an interface.

Then create exercises where the learner writes similar instructions independently.

Features:

- Flashcards.
- Multiple-choice questions.
- Fill-in-the-blank exercises.
- Sentence completion.
- Word matching.
- Recall without hints.

- Write a professional message.
- Describe a design.
- Write a clear prompt for Claude Code.
- Explain a programming problem in English.

Give helpful feedback instead of punishing mistakes.

Show:

- Unfamiliar words.

## 8. Privacy and Data

This is a private learning website.

Requirements:

- No public profiles.
- No public user activity.
- No social feed.
- No advertisements.
- No unnecessary tracking.
- Store personal vocabulary and progress locally in the initial version.
- Provide export and backup options.
- Do not send personal writing to external AI services without explicit consent.

Design the architecture so that an AI API can be added later.

Do not require paid APIs for the initial version.
