# WORDCRAFT ACADEMY — MASTER DESIGN AND UI/UX INSTRUCTIONS

Act as my senior product designer, creative director, UI/UX designer, design-system architect and frontend engineer.

Your mission is to create a premium, visually distinctive educational platform.

## 1. Design Research

Before coding:

- Study relevant design inspiration from Dribbble, Behance and Figma community projects.
- Research modern educational platforms.
- Explore language-learning products and productivity dashboards.
- Identify what makes their interfaces attractive and easy to use.
- Do not copy existing designs.
- Explain the design direction you recommend.

## 2. Visual Identity

Create a recognizable brand identity.

Define:

- Brand personality.
- Primary and secondary colors.
- Background colors.
- Typography system.
- Font pairings.
- Icon style.
- Border styles.
- Shadows.
- Spacing scale.
- Border radius.
- Button styles.
- Interactive states.

Create consistent design tokens using CSS variables.

Avoid generic AI dashboard aesthetics.

## 3. Layout Design

Design each page individually.

Required pages:

- Dashboard.
- Vocabulary Explorer.
- Vocabulary Learning Cards.
- Unfamiliar Words.
- Known Words.
- Sentence Builder.
- Writing Studio.
- Developer English.
- Communication Academy.
- Challenges.
- Progress Dashboard.
- Settings.

For each page, consider:

- Navigation hierarchy.
- Content hierarchy.
- Page width.
- Sidebar behavior.
- Header structure.
- Main content layout.
- Card placement.
- Empty states.
- Loading states.
- Error states.
- Responsive behavior.

Do not make every page look identical.

## 4. Component Design

Create reusable components:

- Sidebar.
- Navigation menu.
- Header.
- Search bar.
- Vocabulary card.
- Word knowledge selector.
- Progress indicator.
- Flashcard.
- Exercise card.
- Writing editor.
- Feedback panel.
- Achievement card.
- Modal.
- Tooltip.
- Dropdown.
- Toast notifications.

Every interactive component must have working functionality.

## 5. Typography

Use typography that makes learning comfortable.

Prioritize:

- Readability.
- Clear heading hierarchy.
- Comfortable line height.
- Appropriate font sizes.
- Good text contrast.
- Consistent font weights.

Choose fonts suitable for both children and adults without making the adult experience childish.

## 6. Interaction and Motion

Add meaningful interactions:

- Hover states.
- Focus states.
- Smooth transitions.
- Card selection feedback.
- Flashcard flipping.
- Progress animations.
- Sidebar transitions.
- Dropdown interactions.
- Keyboard navigation.
- Subtle success animations.

Avoid unnecessary animation.

Respect reduced-motion preferences.

## 7. Responsive Design

Test:

- Desktop.
- Laptop.
- Tablet.
- Mobile.

Do not simply shrink desktop layouts.

Create suitable mobile navigation and responsive vocabulary cards.

## 8. Accessibility

Follow good accessibility practices:

- Semantic HTML.
- Keyboard navigation.
- Accessible forms.
- Visible focus indicators.
- Appropriate contrast.
- Screen-reader labels.
- Clear error messages.
- Accessible interactive controls.

## 9. Quality Control

After implementing a page:

1. Run the application.
2. Inspect it in a real browser.
3. Test its interactions.
4. Check different screen sizes.
5. Identify visual inconsistencies.
6. Fix layout problems.
7. Check console errors.
8. Verify accessibility.
9. Report what was tested.

Do not claim something works without testing it.

## 10. My Learning Requirements

I am learning programming and design.

Explain important design decisions in simple English.

Teach me vocabulary such as:

- Visual hierarchy.
- Whitespace.
- Typography.
- Contrast.
- Alignment.
- Grid system.
- Component.
- Responsive layout.
- Design tokens.
- Micro-interaction.

Explain why you choose each design decision.

## 11. Important Workflow

Do not immediately redesign or modify everything.

First inspect the existing project, its framework, components, styling and installed skills.

Then present:

1. Design direction.
2. Reference inspiration.
3. Color palette.
4. Typography.
5. Layout structure.
6. Component architecture.
7. Responsive strategy.
8. Implementation plan.

Wait for my approval before making significant changes.

Build one page at a time and maintain consistent quality across the application.
